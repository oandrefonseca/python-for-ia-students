15  Módulos, pacotes e ambientes (pip e venv)

Um módulo é um arquivo .py com código reutilizável; um pacote/biblioteca é um conjunto de módulos. Este capítulo cobre as duas metades do mesmo assunto: como obter bibliotecas externas (pip, venv) e como importá-las e usá-las.

15.1 Importando módulos

import math
print(math.sqrt(16))      # 4.0
print(math.pi)            # 3.141592...

from random import randint, choice
print(randint(1, 6))      # simula um dado
print(choice(["cara", "coroa"]))

import statistics as st
print(st.mean([4, 8, 6]))     # média
print(st.median([4, 8, 6]))   # mediana

Evite from modulo import *: polui o espaço de nomes e esconde a origem das funções.

15.2 Seus próprios módulos

Qualquer arquivo .py é importável. Se utilidades.py define def normalizar(x): ..., outro arquivo na mesma pasta pode fazer from utilidades import normalizar.

15.3 Instalando pacotes com pip

O pip é o gerenciador de pacotes do Python, que instala bibliotecas do PyPI (Python Package Index):

pip install pandas              # instala
pip install pandas==2.2.0       # versão específica
pip install -U pandas           # atualiza
pip list                        # o que está instalado
pip freeze > requirements.txt   # congela as versões do projeto
pip install -r requirements.txt # reproduz o ambiente em outra máquina

No Colab/Jupyter, prefixe com !: !pip install pandas.

15.4 Ambientes virtuais (venv)

Projetos diferentes exigem versões diferentes das mesmas bibliotecas. O ambiente virtual isola as dependências de cada projeto:

python -m venv .venv            # cria o ambiente na pasta .venv

# Ativação:
source .venv/bin/activate       # Linux/macOS
.venv\Scripts\activate          # Windows

pip install pandas              # instala SÓ neste ambiente
deactivate                      # sai do ambiente
ImportanteReprodutibilidade

O par venv + requirements.txt é o mínimo de reprodutibilidade em Ciência de Dados: qualquer colega (ou você, daqui a seis meses) recria o ambiente exato com dois comandos. O Anaconda/conda resolve o mesmo problema com outra ferramenta.
